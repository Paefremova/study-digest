# Промпт ежедневной сводки

> Для кого: задача ИИ-оператора по расписанию (Claude Code Desktop → Routines → Local и т. п.).
> Когда читать: при заведении задачи — текст после черты вставляется целиком в её инструкции.

Рабочая папка задачи — корень учебной директории, тот каталог, внутри которого лежит `.digest/`.

Пути в промпте относительные, от рабочей папки задачи, — чтобы его можно было
отдать другому человеку вместе с `.digest/`. Промпт предполагает вокруг себя
ровно три вещи: `.digest/` с программой, каталог `<код предмета>/` на каждый курс
из `config.env` и `stash/` внутри него под методички. Больше ничего.

Сводку целиком печатает сама программа: `study state` отдаёт готовый markdown —
сроки, баллы, уведомления, новое в курсах. Claude дописывает только раздел
«Предлагаю начать», для которого нужно прочитать методичку.

Что настраивается отдельными файлами, без правки промпта:

- какие курсы смотреть — строки `COURSE_IGNORE` в `.digest/config.env`;
- как выглядит ответ — `src/study/digest.py`, функция `render`;
- порядок сдачи работ — `docs/lab-submission.md`; личные уточнения — в файле оператора
  (`CLAUDE.md`, `AGENTS.md`) корня учебной директории, у каждого он свой.

---

Собери сводку по учёбе. Работай молча, итог выдай одним сообщением по-русски.

Все пути ниже — от рабочей папки задачи.

Если рабочая папка — путь в WSL (`\\wsl.localhost\…`), а оболочка windows-овая, запускай команды через `MSYS_NO_PATHCONV=1 wsl.exe -d <дистрибутив> -- bash …`: без `MSYS_NO_PATHCONV` подставляется windows-путь, а в однострочниках `bash -lc '…'` теряются значения переменных. Всё длиннее одной команды клади скриптом в `//wsl.localhost/<дистрибутив>/tmp/` и запускай как `bash /tmp/<имя>.sh`. Файлы читай по обычным путям рабочей папки, без `wsl.exe`.

1. Запусти `.digest/study state --pull`. Его вывод — уже готовая сводка в markdown: сроки, баллы, уведомления, новое в курсах (файлы уже скачаны в `<код>/stash/`). Напечатай её как есть: ничего не пересобирай, не сокращай, не добавляй разделов и пояснений. Ничего в ТУИС не отправляй.

2. Если в конце вывода есть раздел «Предлагаю начать», дополни его: открой методичку в `<код предмета>/stash/` и `NOTES.md` предмета, напиши одно-два предложения — что требуется и сколько это примерно займёт, — и готовое первое сообщение для новой сессии в блоке кода:

   ```
   Начинаем <работа> по <предмет>. Методичка: <код>/stash/<файл>.
   Прочитай NOTES.md предмета и предложи план.
   ```

   Порядок сдачи — `.digest/docs/lab-submission.md`; если в файле оператора в корне рабочей папки (`CLAUDE.md`, `AGENTS.md`) есть свои правила сдачи, они главнее. Чего нет ни там, ни там — не выдумывай. Работу не начинай.

3. Если команда завершилась ошибкой — скажи одной строкой, что именно не получилось, и больше ничего не выдумывай.
