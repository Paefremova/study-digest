# Промпт ежедневной сводки

> Для кого: задача ИИ-оператора по расписанию (Claude Code Desktop → Routines → Local и т. п.).
> Когда читать: при заведении задачи — текст после черты вставляется целиком в её инструкции.

Рабочая папка задачи — корень учебной директории, тот каталог, внутри которого лежит `.digest/`.

Пути в промпте относительные, от рабочей папки задачи, — чтобы его можно было
отдать другому человеку вместе с `.digest/`. Промпт предполагает вокруг себя
ровно три вещи: `.digest/` с программой, каталог `<код предмета>/` на каждый курс
из `config.env` и `stash/` внутри него под методички. Больше ничего.

Сводку целиком печатает сама программа: `study state` отдаёт готовый markdown —
сроки, баллы, уведомления, новое в курсах, «Горит». Агент только запускает команду
и отдаёт вывод; ничего не дописывает и файлов не читает.

Что настраивается отдельными файлами, без правки промпта:

- какие курсы смотреть — строки `COURSE_IGNORE` в `.digest/config.env`;
- как выглядит ответ — `src/study/digest.py`, функция `render`.

---

Собери сводку по учёбе. Работай молча, итог выдай одним сообщением по-русски.

Все пути ниже — от рабочей папки задачи.

Команда — `study state --pull` из рабочей папки; если `study` не в PATH, то `python3 .digest/study state --pull` (Windows: `py .digest/study state --pull`, оболочка Git Bash). Только если рабочая папка — путь в WSL (`\\wsl.localhost\…`), а оболочка windows-овая, запускай команды через `MSYS_NO_PATHCONV=1 wsl.exe -d <дистрибутив> -- bash …`: без `MSYS_NO_PATHCONV` подставляется windows-путь, а в однострочниках `bash -lc '…'` теряются значения переменных; всё длиннее одной команды клади скриптом в `//wsl.localhost/<дистрибутив>/tmp/` и запускай как `bash /tmp/<имя>.sh`. Файлы в любом случае читай по обычным путям рабочей папки, без `wsl.exe`.

1. Запусти `study state --pull`. Его вывод — уже готовая сводка в markdown: сроки, баллы, уведомления, новое в курсах (файлы уже скачаны в `<код>/stash/`), «Горит». Напечатай её как есть, целиком: ничего не пересобирай, не сокращай, не добавляй разделов, пояснений и планов, никаких файлов не открывай. Ничего в ТУИС не отправляй, работу не начинай.

2. Если вывод заканчивается строкой «Обновление study: …» или «Блок агента … устарел» — предложи выполнить `study update --check`, а затем `study update --yes` (или `study agent <код>`) и жди согласия; сам не запускай.

3. Если команда завершилась ошибкой — скажи одной строкой, что именно не получилось, и больше ничего не выдумывай.
